Sobre Este Repositorio

Este repositorio documenta mi viaje completo de aprendizaje en Análisis de Datos, siguiendo un roadmap estructurado de 28 días. Aquí encontrarás código Python, modelos de Machine Learning, pipelines ETL, análisis de texto (NLP), dashboards interactivos y proyectos prácticos end-to-end.

Objetivo: Demostrar competencias reales en todo el ciclo de vida de los datos: desde la extracción y limpieza hasta la visualización y storytelling de negocio.

## 🚀 Proyectos Destacados

### 🏆 1. Pipeline End-to-End de Predicción de Ventas (Día 21)
**Stack:** Python, Pandas, Scikit-Learn, Matplotlib, Seaborn

Proyecto completo que simula un flujo de trabajo real de empresa:
- **ETL:** Limpieza y transformación de datos de ventas
- **Feature Engineering:** Creación de variables derivadas (mes, fin de semana, etc.)
- **ML:** Modelo Random Forest para predecir cantidad vendida
- **Resultados:** Exportación de predicciones y análisis de importancia de features

📁 `dia_11_mini_proyecto/pipeline_completo.py`

---

### 🎬 2. Análisis Exploratorio de Netflix (Día 24)
**Stack:** Python, Pandas, Seaborn, Matplotlib

Análisis del catálogo completo de Netflix Movies & TV Shows:
- Limpieza de datos con manejo de valores nulos
- Visualización de tendencias de contenido por año
- Top países productores y géneros más populares
- Insights de negocio sobre la estrategia de contenido

📁 `dia_24_netflix_eda/analisis_netflix.py`

---

### 🏠 3. Predicción de Precios de Vivienda (Día 25)
**Stack:** Python, Scikit-Learn, Random Forest, Regresión Lineal

Modelo de Machine Learning para predecir precios de casas en California:
- Comparación de dos algoritmos (Regresión Lineal vs Random Forest)
- Escalado de características con StandardScaler
- Métricas de evaluación: MAE, RMSE, R²
- Análisis de importancia de features (¿qué hace que una casa sea más cara?)

 `dia_25_prediccion_precios/modelo_prediccion_precios.py`

---

### 📊 4. Dashboard Profesional de Ventas (Día 26)
**Stack:** Power BI, DAX, Storytelling

Dashboard interactivo para toma de decisiones de negocio:
- KPIs: Ventas Totales, Beneficio, Margen de Beneficio %
- Tendencia temporal de ventas
- Desglose por categoría y región
- Medidas DAX personalizadas
- Storytelling con insights accionables

 `dia_26_dashboard_profesional/dashboard_superstore.pbix`
